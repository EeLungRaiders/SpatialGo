1. 棋譜（必須在 Plan 裡選格式）
============================================================

預設建議（可駁）

- 檔案：一份 JSON（例如 .go3d.json），不是 SZ[] 平面 SGF。
- 頭：{ "format":"Go3D", "size":4, "komi":6.5, "coords":"user" }
  coords=user 表示著手是顯示座標 {-3,-1,1,3}；讀檔時 fromUser。
- 著手陣列：
  { "t":"play", "c":"B"|"W", "p":[x,y,z] }
  { "t":"pass", "c":"B"|"W" }
  { "t":"resign", "c":"B"|"W" }
- 可選尾：deadStones 顯示座標列表、scoreResult 快照（讀檔時可重算核對）
- 重現：newGame 後依序 Rules.play／pass／resign（內部 index），
  與現場對局同一套規則；不要另寫一套「只擺子不提子」的重播器。
- UI：英文 Export（下載或 textarea 複製）、Load（貼上或選檔）。
  載入失敗英文錯誤，不要部分下到一半還當成功。

非目標
- 宣稱相容 Sabaki／GoGui／FF[4]
- 變長 N、多局一個檔

2. 領地著色（計分階段）
============================================================

何時畫
- 僅 phase==='ended' 且已有 scoreResult（標死或按 Score 之後）
- playing／Undo 回 playing：清掉著色
- 標死切換後重算：著色跟著新 flood 更新

畫什麼
- 黑地／白地／dame 三種空點（含「死子當空」的格）顏色可辨
- 活子維持黑白球；死子維持淡或 X，不要把死子球塗成領地色
- 預設用空點標記換色或極淡第二套 Points；
  禁止領地 TH2、禁止 2D overlay、禁止每手 clearDom 整盤
- 著色失敗不準再搞壞 extras／滾輪；必要時只出數字（報告寫備案）

picking
- ended 點活子仍標死；點空地不要誤 play
